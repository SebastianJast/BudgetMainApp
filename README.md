# Budget Management Application in C++

## Project Description

The Budget Management Application is a console-based program written in C++ that allows users to manage their expenses and income. The application supports adding income and expenses, tracking the current and previous month's balance, selecting specific periods for analysis, and changing the user's password.

## Features

### User System:

- **Register new users**: Create a new account to start using the budget management tool.
- **Login and logout**: Secure login and logout functionality for users.
- **Change password**: Allows users to change their password.

### Transaction Management:

- **Add income**: Add income to the user's budget.
- **Add expenses**: Add expenses to the user's budget.

### Balance Tracking:

- **Current month's balance**: View the balance for the current month based on entered transactions.
- **Previous month's balance**: View the balance from the previous month based on entered transactions.
- **Select period for balance tracking**: Allows users to select specific periods (e.g., a particular month, quarter, or year) for analysis.
- **Balance changes**: Track balance changes over time for different periods.

### File Handling:

- **Save data to text files**: User and transaction data is saved to text files for persistence across program sessions.

## Technologies

- **Language**: C++
- **File Handling**: `fstream`
- **Program Structure**: Object-Oriented Programming (OOP)

## Requirements

To run the program, you need:

- A C++ compiler (e.g., Code::Blocks)
